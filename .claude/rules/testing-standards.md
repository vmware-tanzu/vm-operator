# Testing standards

Before writing, editing, or reviewing a Go test file in this repository, you MUST use the Read tool on `.sdd/memory/testing-standards.md` (at the repository root) and follow it. It is the authoritative Ginkgo/Gomega standard for this repository: suite bootstrap, test builders, unit/integration patterns, labels, and fake provider setup.
