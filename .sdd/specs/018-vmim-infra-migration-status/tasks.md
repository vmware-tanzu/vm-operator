For a VirtualMachine that exists and is not being deleted, mirror the migration's `Ready` condition, whatever its status, as `VirtualMachineInfraMigrationReady` when it describes the migration's current generation (its `observedGeneration` is at least the migration's `metadata.generation`), with the migration condition's status, its reason (the status when the reason is empty), and its message followed by `@ VirtualMachineInfraMigration/<name>` (the reference alone when the message is empty), without copying `observedGeneration`. Truncate the migration's message, ending in `...`, whenever it would not leave room for the reference within the 32768 characters of a condition message. Add no pause of the VirtualMachine's reconciliation and no validation of `spec.volumeAttributesClassName`, because the existing skip while a vSphere task is running is enough.
