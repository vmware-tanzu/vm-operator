# Commit message standards

- Subject line: imperative mood ("Add unit tests for user authentication", not "Added …" / "Adds …"), capitalized, at most 50 characters, no trailing period.
- Separate the subject from the body with a blank line.
- Body: wrap at 72 characters; explain _what_ changed and _why_. Bullet points (hyphen, hanging indent) are fine.

```
Capitalized, short (50 chars or less) summary

More detailed explanatory text, wrapped at 72 characters. Explain the
problem this change solves and why this approach was chosen.

- Bullet points are okay, too, with a hanging indent for lines that
  wrap
```
