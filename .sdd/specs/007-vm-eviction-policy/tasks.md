## Phase 3 — User Story: CSP admin applies AutomaticVMEvictionPolicy

**Design**: the reconciler repeats the existing per-kind shape once per new kind, matching #1842's `ControlledRebalancingPolicy` precedent, sharing only the kind-agnostic matching/tag/result-recording helpers. Phase 4's kind is added by writing one new `reconcileMandatory<Kind>Policies` function, one new `add<Kind>PolicyRef` function, and one new gated `Watches(...)` line. See `plan.md` "Controller / webhook impact" for the full design (reconciler, `pkg/crd/crd.go` install-gating, and RBAC markers are all per-kind).
